🎯 O QUE É A NOMEIA AÍ

Plataforma Completa para Concurseiros

A Nomeia Aí é uma plataforma inovadora que permite a criação e participação em rankings simulados de concursos públicos, oferecendo análises de desempenho, ciclos de estudo personalizados, e uma comunidade para interação entre candidatos.

🏗️ ESTRUTURA TÉCNICA

Stack Tecnológico

Frontend

  • React 18 + TypeScript
  • Vite (Build otimizado)
  • Tailwind CSS
  • shadcn/ui
  • Lucide Icons

Backend

  • Supabase (PostgreSQL)
  • Row Level Security (RLS)
  • Real-time subscriptions
  • Edge Functions
  • Storage para arquivos

Integrações

  • Stripe (Pagamentos)
  • React Query (Cache)
  • React Router (Navegação)
  • React Hook Form
  • Zod (Validação)

Features

  • Autenticação social
  • Sistema de presença
  • Logs estruturados
  • Dark mode
  • Responsivo (mobile-first)

Arquitetura de Dados

Principais Tabelas:

  • concursos - Rankings e configurações
  • user_rankings - Participação e respostas
  • user_study_cycles - Ciclos de estudo
  • user_profiles - Perfis públicos
  • subscriptions - Assinaturas ativas
