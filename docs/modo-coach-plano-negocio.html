🎯 MODO COACH - PLANO DE NEGÓCIO

Nomeia Aí | Versão 1.0

📊 SUMÁRIO EXECUTIVO

O Modo Coach é uma funcionalidade que permite que profissionais de coaching ofereçam serviços de acompanhamento de estudos para alunos, utilizando toda a infraestrutura da Nomeia Aí como plataforma intermediária.

💰 MODELO DE NEGÓCIO - Todos Ganham!

Receita da plataforma: R$ 171,80/aluno-coach/mês

💼 MODELO DE NEGÓCIO

👨‍🎓 Aluno (Estudante)

Paga: R$ 21,90/mês (Plano Pro)

Contrata coach por fora (valor a combinar)

Acessa todas funcionalidades + acompanhamento do coach

🎯 Coach (Profissional)

Paga: R$ 149,90/mês (Modo Coach - até 25 alunos)

Cobra do aluno o valor que quiser (fora da plataforma)

Fornece acompanhamento profissional para os alunos vinculados

🏢 Plataforma (Nomeia Aí)

Recebe: R$ 21,90 + R$ 149,90 = R$ 171,80/aluno-coach

Fornece infraestrutura completa

📋 MODO DE USO

Para o Coach:

1. Cadastro e Ativação

1. Coach cria conta na Nomeia Aí
2. Assina o Modo Coach (R$ 149,90/mês)
3. Define quantos alunos pode gerenciar

2. Adicionar Aluno

1. Coach solicita email ou ID do aluno
2. Aluno aceita o convite
3. Relacionamento estabelecido
4. Coach ganha acesso à área de estudos

3. Criar Ciclo de Estudos

1. Coach acessa dashboard do aluno
2. Cria ciclo com disciplinas, horários e datas
3. Aluno recebe notificação
4. Aluno cumpre os ciclos normalmente
5. Coach acompanha progresso em tempo real

4. Definir Metas

1. Coach identifica necessidade do aluno
2. Cria meta específica (ex: "50 horas de matemática em 2 semanas")
3. Sistema monitora progresso
4. Coach vê quando aluno completa
5. Pode dar feedback personalizado

5. Visualizar Estatísticas

  • Coach acessa dashboard específico do aluno
  • Vê gráficos de tempo de estudo
  • Compara desempenho entre disciplinas
  • Identifica padrões de comportamento
  • Recebe alertas de alunos que estão abaixo da média

6. Rankings de Desempenho

  • Coach vê posição do aluno em rankings
  • Compara performance do aluno com outros candidatos
  • Identifica onde aluno precisa melhorar
  • Usa dados para criar estratégias personalizadas

🛠️ COMO SERÁ CRIADO

Fase 1: Estrutura de Dados (Semana 1-2)

Tabelas do Banco de Dados:

-- Assinatura do coach CREATE TABLE coach_subscriptions ( id UUID PRIMARY KEY, coach_id UUID REFERENCES auth.users(id), plan_type TEXT, -- 'starter', 'professional', 'enterprise' max_students INTEGER, price DECIMAL, status TEXT, -- 'active', 'cancelled', 'suspended' current_students INTEGER DEFAULT 0, created_at TIMESTAMP, expires_at TIMESTAMP ); -- Relacionamento coach-aluno CREATE TABLE coach_student_relationships ( id UUID PRIMARY KEY, coach_id UUID REFERENCES auth.users(id), student_id UUID REFERENCES auth.users(id), status TEXT, -- 'pending', 'active', 'inactive' coach_notes TEXT, created_at TIMESTAMP ); -- Tarefas criadas pelo coach CREATE TABLE coach_study_tasks ( id UUID PRIMARY KEY, relationship_id UUID REFERENCES coach_student_relationships(id), task_type TEXT, -- 'study_cycle', 'goal', 'note' title TEXT, description TEXT, deadline DATE, priority TEXT, -- 'high', 'medium', 'low' completed_at TIMESTAMP, metadata JSONB, created_at TIMESTAMP );
